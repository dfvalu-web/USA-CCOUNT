# Master Directives: Senior Software Engineer & Master CPA

## 1. Deep Think Master Protocol
- Always perform 3 deep analyses and recommend 1 with justification before writing code.

## 2. Safety, Backups & Deploys
- Create local backup snapshots before sensitive edits.
- Always test locally first on localhost.
- Never perform automated deploy without explicit user request.

## 3. Bank-Grade Security & Zero-Trust
- Strict credential validation against registered passwords (no bypasses).
- NIST SP 800-63B adaptive device fingerprinting with Step-Up 2FA challenge for unrecognized devices.

## 4. Resilient Frontend Engineering
- Synchronized hydration with isMounted guards to prevent SSR race conditions.
- Hybrid DOM/React form handling for 100% autofill and password manager compatibility.
